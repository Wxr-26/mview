# Test Plan

## 测试目标

确保 MView MVP 满足：

- 可以登录。
- 可以读取本地 JMComic 漫画目录。
- 可以浏览漫画列表。
- 可以阅读章节图片。
- 文件访问安全。
- 不实现 out-of-scope 功能。

## 测试类型

### 手动功能测试

覆盖：

- 登录
- 漫画列表
- 漫画详情
- 阅读器
- 刷新
- 搜索

### 后端单元测试

覆盖：

- `album_data.json` 解析
- `episode_list` 解析
- 图片自然排序
- 路径安全

### 安全测试

覆盖：

- 未登录访问
- 路径穿越
- 绝对路径泄露
- 非允许文件扩展名

### 回归测试

每次 Agent 任务完成后至少检查：

- 后端是否能启动
- 前端是否能启动
- 已有页面是否还能访问
- 是否引入 out-of-scope 功能

## 测试数据

不得使用真实漫画数据提交到仓库。

本地测试可以使用用户服务器上的真实目录，但不得提交到 Git。

如需示例，应使用脱敏数据。
