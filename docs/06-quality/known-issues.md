# Known Issues

## 当前已知问题

暂无。

## 预期风险

### 大型漫画库扫描较慢

第一版不使用数据库，大目录可能导致扫描时间较长。

缓解：

- 启动时扫描 + 手动刷新。
- 后续增加缓存。
- 后续再设计数据库。

### album_data.json 字段不稳定

不同 JMComic 版本可能生成不同字段。

缓解：

- 宽松解析。
- 保留 raw data。
- 缺失字段降级。

### episode_list 格式特殊

`episode_list` 可能是字符串形式的 Python tuple。

缓解：

- 使用安全解析。
- 禁止 `eval`。
- 解析失败时从目录推断章节。

### 路径安全风险

项目会读取服务器文件。

缓解：

- 所有图片请求经 PathGuard。
- 验证最终路径位于 `JM_IMAGE_ROOT` 内。
- 前端不接收绝对路径。
