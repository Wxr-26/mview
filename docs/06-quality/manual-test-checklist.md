# Manual Test Checklist

## 登录

- [ ] 打开系统后未登录会跳转登录页。
- [ ] 正确用户名密码可以登录。
- [ ] 错误用户名密码会提示失败。
- [ ] 登出后不能访问受保护页面。

## 漫画列表

- [ ] `/jm` 可以加载。
- [ ] 漫画列表显示 album。
- [ ] 卡片展示标题。
- [ ] 卡片展示封面或占位封面。
- [ ] 搜索 Album ID 可用。
- [ ] 搜索标题可用。
- [ ] 空结果显示空状态。

## 漫画详情

- [ ] 点击卡片进入详情页。
- [ ] 展示完整标题。
- [ ] 展示作者。
- [ ] 展示标签。
- [ ] 展示页数。
- [ ] 展示章节列表。
- [ ] 章节点击可进入阅读器。

## 阅读器

- [ ] 图片按正确顺序显示。
- [ ] 图片纵向滚动阅读。
- [ ] 图片懒加载。
- [ ] 图片加载失败有提示。
- [ ] 返回详情页可用。
- [ ] 移动端宽度基本适配。

## 刷新

- [ ] 点击刷新后后端重新扫描。
- [ ] 刷新成功后列表更新。
- [ ] 刷新失败有错误提示。

## 安全

- [ ] 未登录不能访问 `/api/jm/albums`。
- [ ] 未登录不能访问图片 API。
- [ ] 构造 `../` 路径无法读取根目录外文件。
- [ ] API 响应不包含服务器绝对路径。
- [ ] 错误信息不泄露敏感路径。

## Out-of-scope 检查

- [ ] 没有数据库。
- [ ] 没有下载功能。
- [ ] 没有删除文件功能。
- [ ] 没有移动文件功能。
- [ ] 没有重命名文件功能。
- [ ] 没有阅读进度。
- [ ] 没有收藏和标签编辑。
