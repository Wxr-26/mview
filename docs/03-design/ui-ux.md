# UI / UX

## 设计目标

MView 第一版应优先服务漫画阅读体验。

关键词：

- 简洁
- 深色
- 快速浏览
- 内容优先
- 移动端可用
- 不干扰阅读

## 视觉方向

建议默认深色主题。

原因：

- 漫画阅读时更舒适。
- 适合长时间浏览。
- 与媒体类应用习惯一致。

## 页面结构

第一版页面：

```txt
/login
/jm
/jm/:albumId
/jm/:albumId/read/:chapterId
```

## 登录页

元素：

- 项目名 MView
- 用户名输入框
- 密码输入框
- 登录按钮
- 错误提示

要求：

- 简洁居中。
- 不展示复杂背景。
- 登录失败提示清晰。

## 漫画库页面

布局：

- 顶部栏：
  - MView 标识
  - 搜索框
  - 刷新按钮
  - 登出按钮
- 主区域：
  - 漫画卡片网格

漫画卡片展示：

- 封面
- 标题
- 作者
- 标签
- 页数
- Album ID

标题过长时：

- 最多显示 2 到 3 行。
- 鼠标悬停可显示完整标题，或在详情页完整展示。

## 漫画详情页

展示：

- 大封面
- 完整标题
- 作者
- 标签
- 页数
- 发布时间
- 更新时间
- 简介
- 章节列表

主要操作：

- 阅读第一章
- 进入指定章节
- 返回漫画库

## 阅读器页面

阅读器应尽量减少干扰。

布局：

- 顶部轻量工具栏
  - 返回
  - 标题
  - 章节切换
- 主体
  - 纵向显示图片
  - 图片居中
  - 根据屏幕宽度自适应
- 错误状态
  - 单图加载失败显示占位

MVP 阅读模式：

- 纵向滚动
- 单列
- 图片懒加载

不做：

- 阅读进度
- 双页模式
- 右到左翻页
- 复杂快捷键
- 全屏模式

## 移动端适配

最低要求：

- 登录页可用。
- 漫画卡片可在窄屏展示。
- 阅读器图片宽度适配屏幕。
- 顶部工具栏不遮挡太多内容。

## 空状态

需要设计：

- 没有扫描到漫画。
- 搜索无结果。
- 章节无图片。
- 图片加载失败。

## 加载状态

需要设计：

- 页面加载中。
- 刷新扫描中。
- 图片加载中。

## 错误状态

错误提示应简洁，不暴露服务器绝对路径。

例如：

```txt
该漫画目录无法读取。
该章节没有可用图片。
图片加载失败。
登录已过期，请重新登录。
```
