# Phase 1: Foundation

## 目标

建立前后端项目基础骨架，但不实现完整业务。

## BE-001：初始化后端项目骨架

### 目标

创建 FastAPI 后端基础结构。

### 范围

允许：

- 创建 `backend/` 下的 Python 项目结构。
- 创建 FastAPI app。
- 创建 `/api/health`。
- 创建配置读取基础。
- 添加基础运行说明。

禁止：

- 实现 JM 扫描。
- 实现图片读取。
- 实现数据库。
- 实现下载功能。

### 验收标准

- 后端可以启动。
- `/api/health` 返回正常。
- 配置模块可以读取环境变量。
- 没有数据库依赖。

## FE-001：初始化前端项目骨架

### 目标

创建 React + TypeScript + Vite 前端基础结构。

### 范围

允许：

- 初始化前端工程。
- 创建基础路由。
- 创建页面占位。
- 创建基础布局。
- 添加运行说明。

禁止：

- 接入真实 JM API。
- 实现复杂 UI。
- 实现业务逻辑。

### 验收标准

- 前端可以启动。
- `/login`、`/jm`、详情页、阅读器路由存在。
- 页面显示占位内容。
- 没有真实业务数据写死。

## QA-001：基础结构审查

### 目标

检查前后端项目结构是否符合文档。

### 检查点

- 目录结构是否清晰。
- 是否越权实现业务功能。
- 是否引入数据库。
- 是否提交敏感文件。
- 是否有运行说明。
