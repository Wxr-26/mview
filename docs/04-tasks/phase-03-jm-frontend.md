# Phase 3: JM Frontend

## 目标

实现 Web 端 JM 漫画浏览与阅读流程。

## FE-002：API Client 和鉴权状态

实现：

- API client
- 登录请求
- 当前用户状态请求
- 401 统一处理

## FE-003：登录页

实现：

- 用户名输入
- 密码输入
- 登录按钮
- 登录错误提示
- 成功后跳转 `/jm`

## FE-004：漫画列表页

实现：

- 获取漫画列表
- 显示漫画卡片
- 搜索
- 手动刷新
- 加载状态
- 空状态
- 错误状态

## FE-005：漫画详情页

实现：

- 展示标题
- 展示封面
- 展示作者、标签、页数、日期等
- 展示章节列表
- 点击章节进入阅读器

## FE-006：漫画阅读器

实现：

- 获取章节页面列表
- 纵向展示图片
- 图片懒加载
- 返回详情页
- 图片加载失败提示

不做：

- 阅读进度
- 收藏
- 双页模式
- 文件管理

## UI-001：阅读体验审查

检查：

- 阅读器是否干净。
- 图片宽度是否适配。
- 移动端是否能阅读。
- 顶部工具栏是否干扰过多。

## QA-003：前端流程审查

检查：

- 未登录是否跳转登录。
- API 错误是否处理。
- 搜索是否工作。
- 刷新是否工作。
- 详情页和阅读器路由是否正确。
