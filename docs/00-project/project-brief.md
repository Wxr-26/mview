# MView Project Brief

## 项目名称

MView

## 项目定位

MView 是一个部署在个人 Linux 服务器上的自托管媒体浏览系统。

第一版 MVP 不做完整媒体平台，而是优先实现：

> 基于本地 JMComic 下载目录的只读 Web 漫画阅读器。

长期方向是逐步扩展为个人媒体浏览系统，支持漫画、图片、视频等多种本地媒体资源。

## 第一版核心目标

第一版需要让用户可以通过浏览器访问服务器上的本地 JMComic 漫画库，并完成基本阅读流程：

1. 读取本地 JMComic 下载目录。
2. 扫描 album 目录。
3. 解析 `album_data.json`。
4. 展示漫画列表。
5. 展示漫画详情和章节。
6. 进入章节阅读页面。
7. 安全读取图片文件。
8. 保持系统只读，不修改原始媒体文件。

## 当前默认本地漫画源

```txt
/mnt/hdd/JMDownload/images
```

目录结构预期：

```txt
images/
└── {album-id}/
    ├── album_data.json
    └── {chapter-id}/
        ├── image files
        └── ...
```

## 当前使用环境

- 部署位置：用户个人 Linux 服务器
- 网络环境：校园网 / 局域网
- 校外访问：通过校园 VPN
- 用户范围：单用户
- 首次访问端：Web 浏览器
- 后续可能扩展：移动 App

## 第一版不做

- 不做数据库
- 不做 JMComic 下载功能
- 不做阅读进度
- 不做视频断点续播
- 不做文件删除、移动、重命名、上传
- 不做多用户权限系统
- 不做公网部署方案
- 不做复杂标签、收藏、评分系统
