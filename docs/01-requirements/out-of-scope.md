# Out of Scope

本文档记录第一版 MVP 明确不做的内容。任何 Agent 不得在未被明确授权的情况下实现这些功能。

## 数据库

第一版不使用数据库。

原因：

- 当前数据源已经存在于本地目录和 `album_data.json`。
- 后续接入 JMComic 下载后，数据模型可能需要重新设计。
- 过早建库会增加迁移成本。

## JMComic 下载

第一版不调用 JMComic 下载功能。

不做：

- 搜索 JM
- 下载 Album
- 下载章节
- 下载队列
- 更新漫画
- 登录 JM
- Cookie 配置
- 下载失败重试

## 文件管理

第一版不提供任何修改原始文件的能力。

不做：

- 删除文件
- 移动文件
- 重命名文件
- 上传文件
- 新建文件夹
- 批量整理

## 阅读和播放进度

第一版不记录：

- 漫画读到第几页
- 最近阅读
- 视频播放到哪里
- 继续阅读
- 继续播放

## 多用户

第一版不支持：

- 注册
- 多用户
- 角色权限
- 访客访问
- 分享链接

## 视频高级能力

第一版不做：

- 字幕
- 倍速
- 转码
- 清晰度切换
- 投屏
- 断点续播

## 复杂媒体管理

第一版不做：

- 收藏
- 标签编辑
- 评分
- 自定义分类
- 推荐
- AI 识别
- 元数据刮削

## 公网部署

第一版以局域网 / 校园 VPN 访问为前提。

不做：

- 公网域名访问方案
- HTTPS 自动证书
- 反向代理安全加固
- OAuth / 2FA
