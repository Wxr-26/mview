# Roadmap

## Phase 0：项目初始化

目标：建立仓库、目录、文档、Agent 协作规则。

状态：进行中。

交付物：

- GitHub 仓库
- 基础目录结构
- 基础文档
- Agent prompt/report 规范

## Phase 1：项目基础骨架

目标：初始化前后端工程。

后端：

- FastAPI 项目骨架
- 配置读取
- 健康检查接口
- 基础鉴权占位

前端：

- React + TypeScript + Vite 项目骨架
- 路由结构
- 基础布局
- 登录页占位

## Phase 2：JM 后端能力

目标：实现本地 JMComic 数据源读取。

交付：

- JM 根目录扫描
- `album_data.json` 解析
- `episode_list` 安全解析
- 章节图片扫描
- 图片安全读取 API
- 手动刷新 API

## Phase 3：JM 前端阅读体验

目标：实现完整浏览和阅读流程。

交付：

- 登录页接入
- 漫画列表页
- 漫画详情页
- 章节阅读器
- 图片懒加载
- 搜索

## Phase 4：部署与稳定性

目标：能在 Linux 服务器上稳定运行。

交付：

- Docker / 非 Docker 启动方案
- 环境变量说明
- 局域网访问说明
- 安全检查
- README 更新

## Phase 5：扩展媒体浏览

目标：从 JM 阅读器扩展为个人媒体浏览器。

可能功能：

- 普通图片浏览
- 视频浏览
- 视频原生播放
- 通用文件夹浏览

## Phase 6：数据与管理能力

目标：引入持久化与管理能力。

可能功能：

- 数据库
- 阅读进度
- 收藏
- 标签
- 文件删除 / 移动 / 重命名
- 操作日志
- 回收站

## Phase 7：JMComic 下载集成

目标：接入 JMComic 下载能力。

可能功能：

- 输入 Album ID 下载
- 下载队列
- 下载进度
- 失败重试
- 更新已有漫画
- 下载配置管理
