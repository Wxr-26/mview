# MVP Scope

## MVP 定位

第一版 MVP 是：

> 部署在 Linux 服务器上的本地 JMComic Web 阅读器。

不是完整媒体平台。

## P0 必须实现

### 用户与访问

- 单用户登录
- 登出
- 登录状态检查
- 受保护 API

### JM 本地漫画源

- 从环境变量读取 `JM_IMAGE_ROOT`
- 扫描 JM 根目录
- 识别 album 目录
- 读取 `album_data.json`
- 解析章节信息
- 扫描章节图片
- 图片自然排序

### Web 页面

- 登录页
- 漫画库页面
- 漫画详情页
- 漫画阅读器页面

### 图片访问

- 后端安全读取图片
- 禁止暴露绝对路径
- 防止路径穿越
- 图片接口鉴权

### 基础体验

- 封面展示
- 图片懒加载
- 手动刷新扫描
- 基础错误提示

## P1 应该实现

- 按标题搜索
- 按 Album ID 搜索
- 作者和标签展示
- 空目录提示
- 损坏 album 提示
- 图片加载失败占位
- 移动端基础适配
- 深色主题

## P2 可延后

- 普通图片浏览
- 视频浏览
- 收藏
- 标签管理
- 评分
- 阅读进度
- 最近阅读
- 数据库
- JMComic 下载
- 下载队列
- 文件删除 / 移动 / 重命名
- 视频倍速
- 视频转码

## MVP 成功标准

MVP 成功不是功能多，而是满足：

- 可以稳定浏览现有 JM 漫画库。
- 阅读体验基本可用。
- 文件访问安全。
- 项目结构清晰。
- 后续扩展不会被第一版设计锁死。
