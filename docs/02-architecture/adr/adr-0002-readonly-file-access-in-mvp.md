# ADR-0002: Read-only File Access in MVP

## Status

Accepted

## Context

MView 会读取 Linux 服务器上的真实媒体文件。

如果第一版就实现删除、移动、重命名或上传，会引入误操作风险、权限风险和路径安全风险。

## Decision

第一版 MVP 只读访问本地媒体文件。

禁止实现：

- 删除
- 移动
- 重命名
- 上传
- 新建文件夹
- 批量整理

## Consequences

优点：

- 降低误删风险。
- 降低实现复杂度。
- 更容易保证路径安全。
- 更适合快速完成 MVP。

缺点：

- 无法直接在 Web 端管理文件。
- 后续如果要管理文件，需要额外设计权限、确认、回收站和日志。

## Follow-up

后续如实现删除功能，建议先实现“移动到回收站目录”，不要直接永久删除。
